EXPERIMENT 12 - INSUREEASY INSURANCE MANAGEMENT SYSTEM

HOW TO RUN
1. Extract the ZIP file.
2. Open the Experiment_12_InsureEasy folder.
3. Double-click index.html or open it in Chrome/Edge/Firefox.
4. No installation or internet connection is required.

FEATURES
- Browse and filter Health, Auto, and Home insurance policies.
- Search policies by name or type.
- Add/remove policies in the My Policies dashboard.
- Submit a sample claim request.
- Demo policy selections are saved in the browser using localStorage.
- Responsive layout for desktop and mobile screens.

IMPORTANT
This is a front-end lab demonstration. It does not connect to a real database, authenticate users, process payments, send SMS messages, or submit real insurance claims. Do not enter real sensitive information.

FILES
index.html      Main web page
style.css       Styling and responsive layout
script.js       Search, filtering, policy management, and claim form logic
sample_output.txt  Example output to describe during the lab
